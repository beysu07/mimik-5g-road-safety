# Veri Klasörü

Bu klasör, proje geliştirme sürecinde kullanılan veri yapısını göstermek için ayrılmıştır.

Gerçek yarışma verileri, test videoları, plaka bilgileri, kişisel veriler ve API bağlantı bilgileri bu repoya yüklenmez.

## Önerilen Yerel Veri Yapısı

```text
data/
├── raw/
├── processed/
├── annotations/
└── sample/
```

Bu klasörlerden `raw`, `processed` ve `annotations` yerel ortamda kullanılmalı; GitHub'a gönderilmemelidir.

## Güvenlik Notu

Bu repoya yalnızca gizli bilgi içermeyen örnek dosyalar veya açıklama dokümanları eklenmelidir.
