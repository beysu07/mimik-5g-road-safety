# MİMİK – 5G Destekli Akıllı Yol Güvenliği Sistemi

MİMİK, yol kenarı kamera görüntülerinden araç, plaka, hız, araç içi nesne ve sürücü davranışı gibi güvenlik kritik bilgileri çıkarmayı hedefleyen; kritik analiz anlarında 5G Quality on Demand API ile ağ kalitesini dinamik olarak artırmayı amaçlayan yapay zekâ destekli bir akıllı yol güvenliği sistemidir.

## Amaç

Bu proje, TEKNOFEST 2026 5G & Yapay Zekâ ile Akıllı Yol Güvenliği Yarışması kapsamında geliştirilmektedir. Sistem, yapay zekâ tabanlı görüntü işleme ile 5G ağ API yeteneklerini bir araya getirerek gerçek zamanlı yol güvenliği analitiği üretmeyi hedefler.

## Temel Bileşenler

- Araç tespiti
- TOGG tespiti
- Plaka okuma
- Hız tahmini
- Araç içi nesne analizi
- Sürücü davranışı analizi
- Quality on Demand API entegrasyonu
- Number Verification API ile kullanıcı doğrulama
- Mobil uygulama arayüzü

## Sistem Mimarisi

Proje dört ana katmandan oluşmaktadır:

1. Görüntü Yakalama Katmanı
2. Mobil Uygulama ve 5G API Katmanı
3. Yapay Zekâ Çıkarım Katmanı
4. Kullanıcı Arayüzü Katmanı
